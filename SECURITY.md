# Security policy

## Reporting a vulnerability

Do **not** open a public GitHub issue for a security vulnerability in mooDesk. Issues in this
repository are public.

Report it privately by email to [support@moodesk.io](mailto:support@moodesk.io), with a subject
line starting with `[Security]`.

## What to include

- The mooDesk version (*Site administration → Plugins → Plugins overview*, `local_moodesk`)
- The Moodle version
- Steps to reproduce the issue
- The impact: what an attacker could do, and which roles or permissions are needed

## What not to include

- Credentials of any kind: passwords, API keys, access tokens, licence keys
- Personal data, yours or your users'
- Database dumps, full configuration files or unsanitised logs

If a log excerpt helps, remove tokens, email addresses, hostnames and IDs first.

## Everything else

Bug reports, feature requests and documentation issues go through
[GitHub Issues](https://github.com/digital-mood/moodesk-support/issues/new/choose).
