# Support

mooDesk support is handled publicly through GitHub Issues in the
[moodesk-support](https://github.com/digital-mood/moodesk-support) repository.

## Report a bug

Found something that doesn't work as expected?
[Open a bug report](https://github.com/digital-mood/moodesk-support/issues/new?template=bug_report.yml).

## Request a feature

Have an idea to improve mooDesk?
[Open a feature request](https://github.com/digital-mood/moodesk-support/issues/new?template=feature_request.yml).

## Report a documentation issue

Found an error, gap or unclear content in these docs?
[Open a documentation issue](https://github.com/digital-mood/moodesk-support/issues/new?template=documentation_issue.yml).

## Private contact

Some topics do not belong in a public issue. Write to
[support@moodesk.io](mailto:support@moodesk.io) for:

- **Security vulnerabilities** — use a subject line starting with `[Security]`, and see the
  [security policy](https://github.com/digital-mood/moodesk-support/blob/main/SECURITY.md)
  for what to include.
- **Licence and account questions** — getting, renewing or replacing a licence key.

Bug reports, feature requests and documentation issues still go through GitHub Issues, using
the links above.

## Before you post

::: danger Never share sensitive information
Issues are public. Do **not** include passwords, API keys, access tokens, personal data,
or production database dumps. If you attach logs, remove tokens, email addresses,
hostnames and IDs first.
:::
